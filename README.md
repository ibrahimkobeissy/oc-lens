# oc-lens

A local-only, read-only analytics dashboard for [opencode](https://github.com/sst/opencode): it reads `~/.local/share/opencode/opencode.db` and shows sessions, tokens, cost, tools, errors, agents, projects, activity, and conversation replay — see `project-docs/backlog.md` for the full v1 scope and `project-docs/opencode-data-model.md` for the data it reads.
